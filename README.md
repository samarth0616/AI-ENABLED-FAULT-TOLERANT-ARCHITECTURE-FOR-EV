A low-cost, fault-tolerant Battery Management System (BMS) designed for a small-scale prototype electric vehicle. The system uses dual redundant 3S2P lithium-ion battery packs with per-cell voltage/current monitoring via three INA219 sensors, and an ESP32 microcontroller running an embedded decision-tree classifier to detect over-voltage, under-voltage, over-current, cell-imbalance, and short-circuit faults in real time. Detected faults trigger a two-layer protection response: a microsecond-scale optocoupler-isolated MOSFET bypass, backed by an electromechanical relay failsafe that switches to a backup pack if the solid-state stage fails. Includes a 2.8" TFT display for live pack health/fault status and a fully dimensioned 4WD chassis design. Demonstrates meaningful fault tolerance on low-cost embedded hardware without cloud inference or heavyweight ML frameworks.
